# 漫画格式智能判断规范

不是所有段子都适合四宫格。**先判断段子的剧情节点数，再选择最佳格式**。

每次接到段子时，**必须先做格式判断**，再开始写脚本。

---

## 一、段子复杂度判断流程

### Step 1：拆解剧情节点

把段子拆解成**关键动作/对话节点**，每一个独立的"动作或转折"算 1 个节点。

**示例：**

```
段子：老公手势魔术撩老婆讨生活费，给了一块钱。

节点拆解：
①  手指连成一条线          ← 节点1
②  老婆切第一刀 → 爱心      ← 节点2
③  老婆切第二刀 → 比心      ← 节点3
④  吹气 → "加倍爱你"        ← 节点4
⑤  男主开口讨生活费         ← 节点5
⑥  老婆掏出一沓钱           ← 节点6
⑦  数钱（数很多）           ← 节点7 ⭐关键铺垫
⑧  只给一块                ← 节点8 ⭐爆点

总共：8 个节点
```

### Step 2：根据节点数选格式

| 节点数 | 推荐格式 | 适用平台 |
|---|---|---|
| **2-3 个** | 三宫格 | 朋友圈、微博 |
| **4 个** | **标准四宫格**（每格1节点）⭐ | 小红书、头条 |
| **5-6 个** | 六宫格 / 上下两屏 / 双四宫格连发 | 小红书、头条 |
| **7-8 个** | **四宫格双镜头**（每格2节点）⭐⭐ | 小红书、头条、抖音 |
| **7-8 个** | 八宫格 / 短视频分镜 | 抖音、视频号 |
| **9+ 个** | 九宫格 / 视频 | 抖音、B站 |

## 二、四种推荐格式详解

### 格式 A：标准四宫格（4 节点）

```
┌──────┐
│  ①   │  铺垫
├──────┤
│  ②   │  递进
├──────┤
│  ③   │  误判
├──────┤
│  ④   │  爆点 ⭐
└──────┘

✅ 经典结构，最容易传播
✅ 制作成本最低
⚠️ 只适合 4 节点以内的段子
```

---

### 格式 B：四宫格双镜头（7-8 节点）⭐⭐ 推荐

每格内部承载 **2 个连续镜头**，信息密度翻倍但保持四宫格经典感。

```
┌─────────────────────┐
│  [镜头1]→[镜头2]    │  铺垫（甜蜜）
├─────────────────────┤
│  [镜头3]→[镜头4]    │  递进（升级）
├─────────────────────┤
│  [镜头5]→[镜头6]    │  误判（埋钩）
├─────────────────────┤
│  [镜头7]→[镜头8]    │  爆点 ⭐ 双层构图
└─────────────────────┘

✅ 节点完整保留
✅ 制作成本不变（仍是 4 张图）
✅ 反转效果完整释放
✅ 多平台通用
```

#### 一格双镜头的 4 种实现技巧

**技巧 ① 连环动作分镜**
- 一格内画人物的两个连续动作
- 用箭头/运动线连接
- 适合：手势变化、动作连续场景

**技巧 ② 单画面 + 多对白气泡**
- 画一个最有冲击力的画面
- 用 2-3 个气泡按阅读顺序承载多个时间点对白
- 适合：场景相似但对白推进的场景

**技巧 ③ 漫画分屏**
- 一格画面斜切/上下分成两个小画面
- 适合：场景转换或主体切换

**技巧 ④ 双层画面**（专为爆点格）⭐
- 前景 + 后景双层信息
- 例：背景"一沓钱"+ 前景"1元钞"超大特写
- 完美保留视觉反差

---

### 格式 C：双四宫格连发（系列化）

```
第一篇 ── 撩+铺垫篇 ── 4 格
                ↓
        （留钩子，悬念结尾）
                ↓
第二篇 ── 反转+爆点篇 ── 4 格

✅ 一份素材产出两条内容
✅ 制造"上下集"悬念
✅ 涨粉效率翻倍（追更心理）
✅ 适合系列化运营
```

**第一篇结尾必须留钩子：**
- "结果你猜怎么着..."
- "下一秒老婆做了一件事..."
- "我万万没想到..."

---

### 格式 D：抖音短视频分镜（8 节点）

```
30 秒视频，8 个分镜，每个 3-4 秒：

00:00-03  镜头①
00:03-06  镜头②
...
00:25-30  镜头⑧（爆点 + 截图引导）

✅ 节奏紧凑，完播率高
✅ 抖音算法最爱
✅ 加配音 + BGM 效果炸裂
✅ 抖音/视频号/B站通用
```

## 三、多平台一鱼多吃策略

**同一个素材，按以下顺序分发：**

```
🎬 第 1 天：抖音短视频（格式 D）          ── 主战场
        ↓
📱 第 2 天：小红书四宫格双镜头（格式 B）   ── 引流
        ↓
📰 第 3 天：头条四宫格双镜头（格式 B）     ── 长尾流量
        ↓
📱 第 4 天：双四宫格连发上集（格式 C）     ── 微信视频号
        ↓
📱 第 5 天：双四宫格连发下集（格式 C）     ── 持续涨粉
```

**1 个段子 = 5 条内容 = 5 波流量** 🔥

## 四、输出流程（必须遵守）

### 收到用户主题时的标准流程

```
1. 拆解节点
   → 列出所有剧情节点（编号①②③...）

2. 判断格式
   → 根据节点数选择推荐格式
   → 告知用户："这个段子有 X 个节点，建议用 XXX 格式"

3. 询问偏好（可选）
   → "你打算发哪个平台？"
   → "需要单格式还是多平台一鱼多吃？"

4. 输出脚本
   → 按选定格式输出完整脚本
   → 每格包含：场景 + 表情 + 构图 + 对白 + 特效
```

### 默认行为

如果用户没有指定格式：

- **节点数 ≤ 4**：直接用标准四宫格
- **节点数 5-6**：默认推荐"双四宫格连发"
- **节点数 7-8**：默认推荐"四宫格双镜头"⭐
- **节点数 9+**：默认推荐"抖音短视频分镜"
