# 漫画格式智能判断规范

不是所有段子都适合四宫格。**先判断段子的剧情节点数，再选择最佳格式**。

每次接到段子时，**必须先做格式判断**，再开始写脚本。

---

## 一、段子复杂度判断流程

### Step 1：拆解剧情节点

把段子拆解成**关键动作/对话节点**，每一个独立的"动作或转折"算 1 个节点。

**示例：**

```
段子：老公手势魔术撩老婆讨生活费，给了一块钱。

节点拆解：
①  手指连成一条线          ← 节点1
②  老婆切第一刀 → 爱心      ← 节点2
③  老婆切第二刀 → 比心      ← 节点3
④  吹气 → "加倍爱你"        ← 节点4
⑤  男主开口讨生活费         ← 节点5
⑥  老婆掏出一沓钱           ← 节点6
⑦  数钱（数很多）           ← 节点7 ⭐关键铺垫
⑧  只给一块                ← 节点8 ⭐爆点

总共：8 个节点
```

### Step 2：根据节点数选格式

| 节点数 | 推荐格式 | 适用平台 |
|---|---|---|
| **2-3 个** | 三宫格 | 朋友圈、微博 |
| **4 个** | **标准四宫格**（每格1节点）⭐ | 小红书、头条 |
| **5-6 个** | 六宫格 / 双四宫格连发 | 小红书、头条 |
| **7-8 个** | **上下双镜四宫格**（每格上下2小镜）⭐⭐ | 小红书、头条、抖音 |
| **9+ 个** | 抖音短视频分镜 / 九宫格 | 抖音、B站、视频号 |

## 二、四种推荐格式详解

### 格式 A：标准四宫格（4 节点）

```
┌──────┐
│  ①   │  铺垫
├──────┤
│  ②   │  递进
├──────┤
│  ③   │  误判
├──────┤
│  ④   │  爆点 ⭐
└──────┘

✅ 经典结构，最容易传播
✅ 制作成本最低
⚠️ 只适合 4 节点以内的段子
```

---

### 格式 B：上下双镜四宫格（7-8 节点）⭐⭐ 推荐

> 也可叫「八格漫画（4 行 × 2 列）」或「双镜四宫格」。
> 每个大格内部用**上下分镜**结构承载 2 个连续镜头。

#### 整体布局（9:16 竖版，4 大格 × 上下两小镜）

```
┌─────────────────┐
│   [小镜头 ①]    │  ← 第 1 大格 · 上
│ ─ ─ ─ ─ ─ ─ ─ │
│   [小镜头 ②]    │  ← 第 1 大格 · 下
├─────────────────┤  铺垫（甜蜜）
│   [小镜头 ③]    │  ← 第 2 大格 · 上
│ ─ ─ ─ ─ ─ ─ ─ │
│   [小镜头 ④]    │  ← 第 2 大格 · 下
├─────────────────┤  递进（升级）
│   [小镜头 ⑤]    │  ← 第 3 大格 · 上
│ ─ ─ ─ ─ ─ ─ ─ │
│   [小镜头 ⑥]    │  ← 第 3 大格 · 下
├─────────────────┤  误判（埋钩）
│   [小镜头 ⑦]    │  ← 第 4 大格 · 上
│ ─ ─ ─ ─ ─ ─ ─ │
│   [小镜头 ⑧]    │  ← 第 4 大格 · 下
└─────────────────┘  爆点 ⭐
```

#### 为什么必须是「上下分」而不是「左右分」

| 维度 | 左右分镜 ❌ | 上下分镜 ✅ |
|---|---|---|
| **画面比例** | 每个小镜变成超细长条（4.5:16） | 每个小镜变成接近横屏（9:8） |
| **人物展示** | 头身比挤，看不清 | 全身/半身都能容纳 |
| **手机阅读** | 横向拥挤 | 纵向滚动天然舒适 |
| **对白气泡** | 没空间放 | 上下都有充足空间 |
| **AI 出图** | 容易畸形 | 稳定出图 |

➡️ **9:16 竖版漫画，必须用上下分镜！**

#### 上下分镜的 4 种实现技巧

**技巧 ① 上下连环动作**（最自然）
- 上：动作起点
- 下：动作终点
- 中间用淡淡运动线 / 箭头 ↓ 连接
- 适合：手势变化、动作演进

**技巧 ② 上下时间推进**（最常用）
- 上：前一时刻的画面 + 对白
- 下：下一时刻的画面 + 对白
- 适合：对话推进、情绪递进

**技巧 ③ 上下场景切换**
- 上：A 视角 / A 场景
- 下：B 视角 / B 场景
- 适合：双视角对比、镜头切换

**技巧 ④ 上下双层信息**（专为爆点格）⭐
- 上：背景大场景（如"一沓钱"动作模糊）
- 下：前景大特写（如"1元钞"+ 男主石化脸）
- 适合：第④格爆点反差，截图传播力 MAX

#### ✅ 这种格式的优势

- 节点完整保留（8 个）
- 制作成本不变（仍是 4 张大图）
- 上下分镜 = 9:16 视觉天然友好
- 反转效果完整释放
- 抖音 / 小红书 / 头条 / 视频号通用

### 格式 C：双四宫格连发（系列化）

```
第一篇 ── 撩+铺垫篇 ── 4 格
                ↓
        （留钩子，悬念结尾）
                ↓
第二篇 ── 反转+爆点篇 ── 4 格

✅ 一份素材产出两条内容
✅ 制造"上下集"悬念
✅ 涨粉效率翻倍（追更心理）
✅ 适合系列化运营
```

**第一篇结尾必须留钩子：**
- "结果你猜怎么着..."
- "下一秒老婆做了一件事..."
- "我万万没想到..."

---

### 格式 D：抖音短视频分镜（8 节点）

```
30 秒视频，8 个分镜，每个 3-4 秒：

00:00-03  镜头①
00:03-06  镜头②
...
00:25-30  镜头⑧（爆点 + 截图引导）

✅ 节奏紧凑，完播率高
✅ 抖音算法最爱
✅ 加配音 + BGM 效果炸裂
✅ 抖音/视频号/B站通用
```

## 三、多平台一鱼多吃策略

**同一个素材，按以下顺序分发：**

```
🎬 第 1 天：抖音短视频（格式 D）            ── 主战场
        ↓
📱 第 2 天：小红书上下双镜四宫格（格式 B）  ── 引流
        ↓
📰 第 3 天：头条上下双镜四宫格（格式 B）    ── 长尾流量
        ↓
📱 第 4 天：双四宫格连发上集（格式 C）       ── 微信视频号
        ↓
📱 第 5 天：双四宫格连发下集（格式 C）       ── 持续涨粉
```

**1 个段子 = 5 条内容 = 5 波流量** 🔥

## 四、输出流程（必须遵守）

### 收到用户主题时的标准流程

```
1. 拆解节点
   → 列出所有剧情节点（编号①②③...）

2. 判断格式
   → 根据节点数选择推荐格式
   → 告知用户："这个段子有 X 个节点，建议用 XXX 格式"

3. 询问偏好（可选）
   → "你打算发哪个平台？"
   → "需要单格式还是多平台一鱼多吃？"

4. 输出脚本
   → 按选定格式输出完整脚本
   → 每格包含：场景 + 表情 + 构图 + 对白 + 特效
```

### 默认行为

如果用户没有指定格式：

- **节点数 ≤ 4**：直接用标准四宫格
- **节点数 5-6**：默认推荐"双四宫格连发"
- **节点数 7-8**：默认推荐"上下双镜四宫格"⭐
- **节点数 9+**：默认推荐"抖音短视频分镜"
