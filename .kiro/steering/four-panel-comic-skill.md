# AI 漫画生成 Skill（主入口 - 自动激活）

本仓库启用了「AI 漫画生成 Skill」。当用户输入主题、段子、生活故事，
或要求"做成漫画 / 改编漫画 / 生成四宫格 / 做个分镜"时，
**必须严格按照下方完整规范执行**。

---

## 一、收到素材时的标准流程

```
Step 1: 拆解剧情节点（编号①②③...）
Step 2: 判断节点数 → 选择最佳格式
        → 详见 comic-format-selection.md
Step 3: 设计情绪曲线
        → 详见 comic-expression-guide.md
Step 4: 输出完整脚本，包含：
        - 梗概
        - 全局风格 Prompt
        - 男女主角色 Prompt（引用 comic-character-design.md）
        - 每格的「场景 + 表情 + 构图 + 对白 + 特效」
        - 负面约束 Prompt
        - 最终输出规范
        - （可选）配套文案 + 多平台分发建议
```

---

## 二、必须遵守的核心规范（按优先级）

### 1. 角色形象统一（强制）

详见：#[[file:comic-character-design.md]]

- 男主：帅气理工男，瘦高肩宽腰窄，黑框眼镜，邻家男神
- 女主：韩系白月光，凹凸有致但**含蓄不暴露**，自然诱惑力
- **每格必须保持脸型/发型/气质完全一致**

### 2. 表情戏剧化夸张（强制）

详见：#[[file:comic-expression-guide.md]]

- 每个角色每格至少 **3 个具体表情细节**
- 必须设计完整的「情绪曲线」
- 第④格必须形成 **180° 反差**
- **禁止**使用"开心""惊讶"等空洞词

### 3. 格式智能选择（强制）

详见：#[[file:comic-format-selection.md]]

- 节点数 ≤ 4 → 标准四宫格
- 节点数 5-6 → 双四宫格连发
- **节点数 7-8 → 上下双镜四宫格**（每格上下 2 小镜，推荐⭐）
- 节点数 9+ → 抖音短视频分镜

## 五、触发示例

```
用户输入                              → 系统行为

"主题：女朋友说我没生气"              → 拆解节点 → 选格式 → 输出
"帮我做一个纪念日忘记的漫画"          → 同上
"这段子做成漫画：xxxxxx"             → 同上
"今天我和老婆 xxx，改成漫画"         → 同上
"用 4格8镜头 做这个段子"             → 强制用上下双镜四宫格格式
"做成上下双镜"                       → 同上
"做成抖音视频分镜"                   → 强制用 8 分镜视频格式
```

## 六、输出前自检清单

每次输出脚本前，**逐项确认**：

- [ ] 节点是否拆解清楚
- [ ] 格式选择是否合适
- [ ] 角色描述是否引用了标准设定
- [ ] 男主是否帅气、瘦高、戴黑框眼镜
- [ ] 女主是否凹凸有型但**不暴露**
- [ ] 每格表情至少 3 个具体细节
- [ ] 情绪曲线是否递进 + 反转
- [ ] 第④格男女表情是否 180° 反差
- [ ] 头顶特效（爱心/算盘/¥/汗滴等）是否齐全
- [ ] 中文对白气泡是否清晰
- [ ] 是否包含负面约束（含"不暴露"约束）
- [ ] 是否符合 9:16 竖版输出规范

**所有项 ✅ 才能输出。**
