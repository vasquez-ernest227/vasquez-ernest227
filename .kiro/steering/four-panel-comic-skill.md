# AI 四宫格漫画生成 Skill（自动激活）

本仓库启用了「四宫格漫画生成 Skill」。当用户在对话中输入：

```
主题：xxxx
```

或类似格式（例如「帮我做一个关于 xxx 的四宫格」）时，
**必须严格按照下方完整 Skill 规范执行**，自动输出：

1. 梗概总结
2. 四宫格剧情拆解（铺垫 → 递进 → 误判 → 爆点）
3. 全局风格 Prompt
4. 男主 / 女主固定角色 Prompt
5. 第一格 / 第二格 / 第三格 / 第四格独立镜头 Prompt
6. 负面约束 Prompt
7. 最终输出规范（9:16 竖版长图）

## 输出原则

- **必须**有情绪递进 + 最后一格反转
- **必须**保持男女主角色形象统一（每格都用固定设定）
- **必须**包含中文对白气泡描述
- **不要**机械描述、不要 AI 味太重、不要平铺直叙
- 输出风格要像「专业漫画导演 + 小红书高赞漫画 + 短视频分镜」

用户也可以用更口语化的方式触发，例如：
- "帮我生成一个关于纪念日忘记的四宫格"
- "这个梗做成漫画：男生说她不胖结果说错话了"
- "今天我和老婆 xxx，做成漫画"

只要意图是「生成四宫格漫画」，都按本 Skill 执行。
