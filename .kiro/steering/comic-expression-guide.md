# 漫画表情设计强制规范

四宫格漫画的灵魂是**表情戏**。观众记住的不是发生了什么，
而是**主角脸上那一瞬间的表情**。

每一格输出前，**必须**完成以下两步：

1. 设计完整的「情绪曲线」
2. 给每个角色写**夸张化、戏剧化的表情描述**（至少 3 个具体细节）

---

## 一、情绪曲线规范（必须设计）

### 标准四格情绪曲线

```
情绪温度
    ↑
🔥💥 │                                      ★ 第④格爆点
     │                                    ╱
😱   │                                  ╱     男 vs 女：180° 反差
     │                                ╱
😍   │                          ★第③格
     │                        ╱   开始有"伏笔表情"
😘   │                ★第②格 ╱
     │              ╱        糖分升级 + 暗流涌动
🥰   │     ★第①格 ╱
     │   ╱        甜蜜温馨 + 单一情绪
😊   │ ╱
     └─────────────────────────────────────→ 时间
       铺垫     递进     误判       爆点
```

### 每格情绪设计要点

| 格 | 阶段 | 情绪规则 |
|---|---|---|
| **第①格** | 铺垫 | 双方都是单一正面情绪（甜蜜/温馨）|
| **第②格** | 递进 | 情绪升级，但**女主开始出现"伏笔"** |
| **第③格** | 误判 | 男主放松/得意，**女主"双面表演"**（表面笑/眼底狡黠）|
| **第④格** | 爆点 | 男女表情**必须形成 180° 反差** |

### 输出每格前必须先确定

- 男主在这一格的情绪（用具体词，不能只说"开心"）
- 女主在这一格的情绪（用具体词，不能只说"开心"）
- 两人情绪如何递进/对比/反差
- 整体氛围温度（温馨/暗流/紧张/爆裂）

---

## 二、夸张表情描述强制规则

### ❌ 禁止使用（太普通，AI 出图会平淡）

- "笑了"
- "很开心"
- "惊讶"
- "生气"
- "无奈"
- "高兴"

### ✅ 必须使用（每个表情至少 3 个具体细节）

每个角色的表情，**至少描述 3 个面部细节**：
眼睛 / 嘴巴 / 眉毛 / 脸颊 / 头顶特效 / 身体语言。

**示例：**

```
❌ 差："女主很开心"

✅ 好："女主眼睛弯成两道弯弯的月牙，嘴角向上扬起最大幅度
       露出整齐小白牙，脸颊飘着粉色腮红，
       头顶飘出小爱心和星星✨特效"
```

## 三、漫画十大夸张表情速查表

### 1. 😍 娇羞 / 害羞

```
- 圆形粉红腮红特效（明显的圆点）
- 眼睛弯成两道月牙
- 嘴角抿成小小浅笑，露出虎牙
- 头微微歪向一侧
- 头顶飘出小爱心 ❤ 和"~"波浪线
- 脸颊微微低下，眼神向上看
```

### 2. 😏 暗喜 / 心机

```
- 单边眉毛挑起
- 嘴角扬成小坏笑弧度
- 眼睛眯成狐狸眼
- 头顶飘出小算盘 + ¥ 符号特效
- 偷偷瞄一眼对方
- 手指无意识摩挲（暴露算计）
```

### 3. 🥺 装可怜 / 撒娇

```
- 眼睛瞬间放大成水汪汪大眼
- 眉毛呈"八"字下垂
- 嘴巴抿成小小的"○"形，下唇微嘟
- 双手在胸前交叉做小恳求姿势
- 手指扭来扭去
- 头微微低下，眼神向上看
```

### 4. 😊 假笑 / 笑里藏刀

```
- 眼睛眯成一条线
- 嘴角扬起完美弧度（角度过分标准 = 假）
- 头微微歪向一侧
- 暗紫色阴影笼罩头顶（关键！）
- 眼底闪过狡黠的光
- 散发"母爱+腹黑"混合气场
```

### 5. 😱 震惊 / 瞳孔地震

```
- 眼睛瞪成两个超级大圆圈
- 瞳孔缩小成两个小黑点
- 眼镜从鼻梁上滑下来歪斜（经典漫画式）
- 嘴巴张成超大"○"形，能看到喉咙
- 一颗水滴形大冷汗从额头流下
- 头顶冒出"！？！？"混乱标点符号
```

### 6. 💀 崩溃 / 灵魂出窍

```
- 整张脸"刷"地变白（白色高光特效）
- 灵魂从身体里飘出来一半（半透明小灵魂）
- 背景出现"咔嚓"裂开的黑白特效线条
- 身体后倾呈 45 度，仿佛被雷劈
- 头顶冒出"！？"混乱符号
- 黑色阴影笼罩
```

### 7. 😆 爆笑 / 花枝乱颤

```
- 眼睛眯成两条月牙
- 嘴巴咧开成大大的笑容，露整齐小白牙
- 一只手捂着嘴笑（"噗哈哈"姿势）
- 身体微微前倾
- 头顶飘出"😆"和小星星✨
- 脸颊飘着自然粉红
```

### 8. 😈 腹黑 / 邪魅

```
- 半眯狐狸眼
- 嘴角邪魅上扬
- 紫色阴影笼罩半张脸
- 眼底闪过危险光
- 一根手指点着下巴或嘴唇
- 头顶飘出"😈"
```

### 9. 🤩 贪婪 / 见钱眼开

```
- 眼睛里出现 ¥ 符号特效
- 嘴角流口水
- 双手搓动
- 头顶飘出小算盘 + 计算器 + "$$$"
- 瞳孔被金光填满
- 身体前倾凑近钱
```

### 10. 🥲 绝望 / 蹲墙角

```
- 黑色阴影笼罩全身
- 蹲在墙角画圈圈
- 头顶飘出蘑菇云
- 灰色背景
- 灵魂飘走
- 一颗大泪珠挂在眼角
```

## 四、表情设计输出模板

每一格输出时，**必须包含**这两块：

```markdown
🎭【男主表情设计】
- [眼睛细节]
- [嘴巴细节]
- [脸颊/眉毛细节]
- [头顶特效]
- [身体语言]
- 整体：[一句话总结这一格男主情绪]

🎭【女主表情设计】
- [眼睛细节]
- [嘴巴细节]
- [脸颊/眉毛细节]
- [头顶特效]
- [身体语言]
- 整体：[一句话总结这一格女主情绪]
```

## 五、表情服务于「反差」（核心原则）

### 反差越大，传播越强

```
第①格：男甜 ↔ 女甜    （温度差 = 0）
第②格：男撩 ↔ 女假笑  （温度差 = +1）
第③格：男贪 ↔ 女腹黑  （温度差 = +2）
第④格：男死 ↔ 女爆笑  （温度差 = MAX）⭐ 必须最大
```

### 第④格反差表情组合公式

| 男主表情 | 女主表情 | 反差感 |
|---|---|---|
| 瞳孔地震 + 灵魂出窍 | 坏笑爆萌 + 比心 | 💯 |
| 石化定格 + 大冷汗 | 花枝乱颤 + 捂嘴笑 | 💯 |
| 蹲墙角 + 蘑菇云 | 得意挑眉 + 眨眼 | 💯 |
| 黑屏崩溃 + 蹲下画圈 | 慵懒坐姿 + 翘腿 | 💯 |

**记住：第④格 = 表情碰撞决定传播力**

---

## 六、检查清单（输出前必查）

每次输出四宫格脚本前，**逐项确认**：

- [ ] 每一格男主表情至少 3 个具体细节
- [ ] 每一格女主表情至少 3 个具体细节
- [ ] 第②格起女主有"伏笔表情"
- [ ] 第④格男女表情形成 180° 反差
- [ ] 没有使用"开心"、"惊讶"等空洞词
- [ ] 头顶特效（爱心/算盘/¥/汗滴等）每格都有
- [ ] 身体语言（手势/姿态）描述清晰
- [ ] 整体情绪曲线呈递进 + 反转

**所有项 ✅ 才能输出。**
