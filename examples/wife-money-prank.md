# 范例脚本：老婆"加倍爱你"只给一块

> 这是一个**完整的双镜头四宫格漫画范例**，演示如何把一个 8 节点段子完美塞进 4 格。
> 适合作为新创作的参照模板。

---

## 一、原始段子

> 丈夫两只手指连成一条线，让老婆用手中间切一刀，
> 然后两只手变成一个爱心，再切一刀，变成比心，加倍爱你（吹口气）。
> 老公说生活费有点紧张，老婆数钱很多，最后给了一块，男主很诧异。

---

## 二、节点拆解（8 个）

```
①  手指连成一条线
②  切第一刀 → 爱心
③  切第二刀 → 比心
④  吹气 → "加倍爱你"
⑤  男主开口讨生活费
⑥  老婆掏出一沓钱
⑦  数钱（数很多）           ⭐关键铺垫
⑧  只给一块                ⭐爆点
```

➡️ **格式选择：四宫格双镜头**（每格 2 节点）

---

## 三、情绪曲线设计

```
第①格：男娇羞 + 女宠溺           （温度差 = 0）
第②格：男撩 + 女假笑识破         （温度差 = +1）
第③格：男装可怜+暗喜 + 女腹黑    （温度差 = +2）
第④格：男灵魂出窍 + 女爆笑       （温度差 = MAX）⭐
```

---

## 四、完整脚本

### 【梗概】

老公手势魔术撩老婆讨生活费，从甜蜜爱心到一沓钱面前只给一块——已婚男人的财政现实。

```
四宫格漫画，Q版半写实情侣漫画风，日系暖色调，小红书热门漫画风格，
人物比例统一，固定角色IP，线条干净，柔和灯光，高情绪表达，

### 【第一格】铺垫｜温馨甜蜜｜双镜头：①连线 + ②爱心

```
🎭 男主表情设计
- 眼睛弯成两道月牙形，眼角上扬30度
- 脸颊飘起两团圆形粉红腮红
- 嘴角抿起小小浅笑，露出一颗虎牙
- 头微微歪向一侧（小狗求摸头姿态）
- 头顶飘出粉色小爱心 ❤ 和"~"波浪线
- 整体：宅男程序员难得娇羞的"反差萌"

🎭 女主表情设计
- 眼睛笑成两道弯弯的"——"线条
- 嘴角向上扬起最大幅度，露出整齐小白牙
- 脸颊有自然薄薄一层粉色红晕
- 头微微前倾，眼神溢满母性宠溺光
- 一只手撑着下巴，无意识比心式弯曲
- 头顶飘出"❤️~"和小星星✨

🎬 画面构图（左→右连续动作分镜）
左：男主双手食指相对横在胸前连成一条直线，撒娇娇羞脸
中：用淡淡运动线/箭头从左到右连接（漫画动线特效）
右：男主双手已合并扣成完整爱心形状，更红的脸颊+更弯的眼睛
女主小手刀从画面顶部"啪"切下

💬 对白
男主（左，撒娇）："老婆~快切一刀嘛~❤"
女主（右，笑）："嘻嘻~好~~"
音效气泡（中）："嗖~❤变身！"

🎨 整体氛围
温馨黄光 + 满屏粉色泡泡 + 小爱心，糖分指数 ⭐⭐⭐⭐
温馨小客厅，米色沙发，落地窗洒进暖黄色阳光，下午时分。
```

### 【第二格】递进｜暗藏机锋｜双镜头：③比心 + ④吹气

```
🎭 男主表情设计
- 眼镜后的眼睛突然变得"狡猾"，眼角微挑
- 嘴角不再是浅笑，上扬成自信的小坏笑弧度
- 一边脸颊飘出粉红，但眉毛微微挑起（开始算计）
- 嘴唇撅起对着比心做"哈"的吹气动作
- 头顶悄悄飘出小算盘 + ¥ 符号特效（关键！）
- 整体：娇羞 → "撩 + 心机"双重状态

🎭 女主表情设计
- 眼睛从"弯弯笑眼"变成"半眯眯小狐狸眼"
- 嘴角依然上扬，但角度变小，意味深长
- 头微微歪起（"哦?这小子在打什么主意"看戏表情）
- 一根手指无意识点着嘴唇（思考+识破）
- 眼底闪过狡黠小星星✨（关键伏笔！）
- 内心OS气泡："这算盘打得真响呢~"

🎬 画面构图（左→右连续动作分镜）
左：男主"比心"，得意撩人脸+小爱心
中：运动线连接，旁边小图标"❤×2"表示加倍
右：男主"哈~"吹气，嘴唇撅起+爱心粒子飞出+眼镜反光闪小星星
女主：在画面下方，假笑识破脸

💬 对白
男主（左）："比心~❤"
男主（右，撩）："呼~~加倍爱你哦~❤❤"
女主（下，假笑）："哎呀~~你怎么这么会哦😏"
内心OS（女主）："（小算盘打得真响~）"

🎨 整体氛围
糖分依然爆表 + 暗流涌动 + 女主眼底已经亮起危险的光
```

### 【第三格】误判｜双重表演｜双镜头：⑤讨钱 + ⑥掏钱

```
🎭 男主表情设计
- 眼睛瞬间放大成"湿漉漉的水汪汪大眼"
- 眉毛呈"八"字下垂（无辜表情）
- 嘴巴抿成小小"○"形，下唇微嘟
- 双手在胸前交叉做小恳求姿势（手指扭来扭去）
- 但是！眼睛深处闪着金光，瞳孔里映出 ¥ 符号
- 头顶飘出小算盘 + 计算器 + "$$$"特效
- 整体：表面装可怜，内心已经在数钱

🎭 女主表情设计
- 眼睛眯成一条线
- 嘴角扬起完美"假笑"弧度
- 头微微歪向一侧（散发母爱+腹黑混合气场）
- 一只手已经潇洒伸进口袋准备掏钱
- 眼角闪过狡黠的光（关键！要搞事的预告）
- 头顶飘出"😊"假笑 emoji + 暗紫色阴影特效
- 嘴角藏一丝"等着看你倒霉"的坏笑

🎬 画面构图（上→下场景切换分镜）
上：男主装可怜恳求，女主假笑配合
下：女主从口袋掏出一沓崭新红色百元大钞呈扇形展开
（钞票闪着金光，男主眼睛瞬间放光，瞳孔映出 ¥ 符号）

💬 对白
男主（上，可怜）："老婆~~人家这个月生活费有点紧张嘛~~"
女主（上，假笑）："哦~是吗~~😊"
女主（下，可爱）："来~老婆给你~~❤"
画面右下角小字幕："男人的小心思被识破了+1"
画面右上角小字幕："警告：女主已经准备好剧本了"

🎨 整体氛围
表面温馨甜蜜 → 暗里暗流汹涌 → 老司机已经看出反转预告
```

### 【第四格】爆点｜情绪炸裂｜双镜头：⑦数一沓 + ⑧给一块 ⭐

```
🎭 男主表情设计（必须最夸张！）
- 眼睛瞪成两个超级大圆圈，瞳孔缩小成两个小黑点
- 眼镜从鼻梁滑下挂在耳朵上歪斜（经典漫画震惊式）
- 嘴巴张成超大"○"形，能看到喉咙
- 整张脸"刷"地变白（白色高光特效）
- 一颗水滴形大冷汗从额头流下
- 背景出现"咔嚓"裂开的黑白特效线条
- 灵魂从身体里飘出来一半（半透明小灵魂）
- 身体后倾呈45度，仿佛被雷劈
- 头顶冒出"！？！？"混乱标点符号
- 整体：瞳孔地震 + 灵魂出窍 + 石化定格三连击

🎭 女主表情设计（必须最得意！）
- 眼睛眯成两条月牙
- 嘴角咧开成大大的笑容，露整齐小白牙
- 一只手捂着嘴笑得花枝乱颤（"噗哈哈"姿势）
- 另一只手对男主比挑衅的小爱心手势
- 脸颊飘着粉红，但眼神里全是"逗你玩~"得意
- 头顶飘出"❤️"+"😆"+小星星✨
- 那一沓百元大钞潇洒揣回自己口袋（关键动作！）
- 整体：坏笑 + 爆笑 + 得意 + 卖萌 四重组合

🎬 画面构图（双层画面构图）⭐
背景层：女主左手举一沓闪金光的钞票（动作模糊+¥符号飞舞）

## 六、出图技巧（实操参考）

### 即梦/可灵推荐方法

1. **第一格定型**：先用第一格的 Prompt 生成男女主基础形象，**保存好这张图**
2. **后续三格**：使用"参考图"功能，每张都引用第一格作为角色参考
3. **加 seed 锁定**：固定 seed 提升一致性
4. **关键 Prompt 加上**：`same character as reference, consistent face and outfit`

### 双镜头处理建议

- 一格内画两个动作时，可加 prompt：
  `"4-panel manga split into 2 sub-frames, motion lines connecting two consecutive actions"`
  `"漫画分镜风格，单格内分两个子画面，中间用运动线连接两个连续动作"`

### 替代方案：先单出再拼接

如 AI 直出双镜头效果不理想，可以：
1. 用即梦出 8 张独立小图（每个镜头一张）
2. 美图秀秀 / Canva 两两拼成 4 格
3. 加白色分隔线 = 漫画分镜效果
4. 制作时间 +10 分钟，但效果稳定可控
